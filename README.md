# sparkandlilystories.com

The home page for **Little Spark Stories** – calm, gentle, AI-animated bedtime stories for little ones aged 2–5, with Spark, Lily, Luna and Snowy.

Live at: https://sparkandlilystories.com

It is a simple one-page site (`index.html` + `style.css`) used as a link-in-bio page for Instagram, YouTube and TikTok. We use a simple, privacy-friendly visitor counter ([GoatCounter](https://www.goatcounter.com)). No cookies, no personal data, no tracking.

## Images to upload

Put these files in the `images` folder (exact names, lowercase):

- `images/hero.jpg` – main picture at the top (also used when the link is shared)
- `images/spark.jpg`
- `images/lily.jpg`
- `images/luna.jpg`
- `images/snowy.jpg`
- `images/books.jpg`

And this one in the main (root) folder:

- `favicon.png` – the small icon shown in the browser tab (square, e.g. 512×512)

Until an image is uploaded, a soft cream placeholder colour is shown in its place.

Tips: landscape works best for `hero.jpg` (16:9) and `books.jpg` (4:3), and around 1200×630 or larger for `hero.jpg` so shared links look sharp. The four character pictures are shown as squares, so square images with the character centred work best – crop off any pale bands at the edges before uploading.
